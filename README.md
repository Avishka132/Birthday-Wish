# Birthday Website 💗

A simple romantic birthday website built with HTML, CSS and JavaScript. You can edit it in VS Code and host it free with GitHub Pages.

## 1. Open it in VS Code
1. Extract `girlfriend_birthday_website.zip`.
2. Open the extracted `girlfriend_birthday_website` folder in VS Code.
3. Open `index.html` in a browser to preview it. For easier previewing, install the VS Code extension **Live Server**, right-click `index.html`, then choose **Open with Live Server**.

## 2. Add your photos
1. Inside the project folder, create a folder named `photos`.
2. Put your photos in that folder and name them exactly:
   - `our-photo-1.jpg`
   - `our-photo-2.jpg`
   - `our-photo-3.jpg`
3. If your photo is a PNG, either convert it to JPG or change the matching image filename in `index.html`.
4. Use photos you are both happy to share online. Anyone who has the public website link may be able to see the photos.

## 3. Personalize the message
Open `index.html` and search for:
- `My Beautiful Girl` — change this to her name or nickname.
- `Happy Birthday, my love!` — edit the letter.
- `Always yours` — change the sign-off if you want.

You can also change the colors near the top of `style.css` under `:root`.

## 4. Host it on GitHub Pages for free
1. Sign in to GitHub and create a **new public repository**, for example `birthday-for-my-love`.
2. Upload `index.html`, `style.css`, `script.js`, and the `photos` folder (with your images) to the repository's root.
3. On the repository page, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub Pages will show your site URL on the Pages settings screen, usually like `https://YOUR-USERNAME.github.io/birthday-for-my-love/`.

## Notes
- This project does not need Python or a server. HTML + CSS + JavaScript is the easiest choice for a small static birthday site.
- Do not upload private photos or personal details unless you are comfortable with them being available on a public website.
